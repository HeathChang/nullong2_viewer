# 프로젝트 안내서

이 문서는 **한국어 줄바꿈**과 코드 하이라이트, 표를 한꺼번에 확인하기 위한 샘플입니다.
아주 긴 문장을 넣어서 어절 단위로 잘 끊어지는지 살펴봅니다. 한국어는 단어 중간에서 잘리면 매우 읽기 불편합니다.

## 목차 확인용 절

### 하위 항목 하나

목차에서 들여쓰기가 되는지 봅니다. 이 문단은 스크롤 위치를 기억하는지 확인하려고
문서를 충분히 길게 만들기 위한 것이기도 합니다. 한국어 문장이 어절 단위로 잘 끊어지는지,
긴 문단에서도 줄 간격이 편안한지 함께 살펴봅니다.

### 하위 항목 둘

문서에서 찾기(⌘F)로 이 문단의 낱말을 검색해 봅니다. 검색어는 본문 어디에나 있을 수 있고,
같은 낱말이 여러 번 나오면 하나씩 옮겨 다닐 수 있어야 합니다.
